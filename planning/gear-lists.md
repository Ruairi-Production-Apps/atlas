# Gear Lists
This is a new feature. Scouters in an Organisation (Province, County, or Group) can create and edit Gear Lists.
On the 'Organisation' dashboard add tab at the end of the other tabs 'Gear'.

This will have section 'Gear List'.
Users can create, view, edit, and delete these.
A gear list can optionally be linked to an event.

Gear lists have a 'Share' link that can be sent to others to view a frontend page for that Gear List.

A 'Gear' tab appears on the org's frontend page, if there is one or more gear lists. This lists gear lists (standalone from events) and they can be clicked into.

## Making and editing gear lists:
Repeater field of single text inputs.
Optionally a 'Description' rich text field can be filled for 'More Info' which is expandable on the frontend gear list. e.g. to link out to some reccomended products for that gear item type.
